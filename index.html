기획 철학

💡
WHY → WHAT → HOW
기능 정의보다 문제 정의를 먼저 합니다. 비즈니스 요건이 들어오면 "이걸 왜 만들어야 하는가"를 먼저 묻고, 사용자 맥락으로 재해석한 뒤 방향의 근거를 문서로 남깁니다. 직관이 아닌 데이터와 근거가 팀 전체의 판단 기준이 되어야 한다고 믿습니다.
핵심 원칙
🔍
기술 언어를 읽는 기획자
API 명세와 UML 시퀀스를 직접 분석합니다. 개발자와 같은 언어로 논의할 수 있어야 기획 단계에서 구현 리스크를 잡고 재작업을 줄일 수 있다고 생각합니다. NH모바일신분증 구축 당시 인증 플로우의 예외 케이스를 명세 분석으로 사전에 발견해 일정 지연을 막은 경험이 이 믿음을 만들었습니다.
📐
기준을 선제적으로 정의하는 일
UX 문구 가이드, 에러 메시지 원칙, GA 이벤트 네이밍 규칙까지 팀이 매번 판단하지 않아도 되도록 구조를 먼저 설계합니다. 좋은 기획은 기능을 만드는 것뿐 아니라 팀이 더 빠르게 움직일 수 있는 판단 기준을 만드는 일이기도 합니다.
🤝
소통 비용을 설계하는 협업
기획서는 내 생각을 정리하는 문서가 아니라 개발·디자인·QA가 같은 그림을 보는 커뮤니케이션 도구입니다. 플로우차트, 예외 조건 정의, 화면 상태 케이스 분기를 꼼꼼히 담아 "다시 물어볼 필요가 없는" 문서를 만드는 것을 목표로 합니다.

NH올원뱅크 앱 고도화
WHY
앱 내 구형 OAB 디자인 화면들로 인해 이용자 수 감소 및 대표앱 이미지 구축 어려움 식별. 주이용자가 중년층에 집중돼 젊은층 확대와 중년층 편의성 개선을 동시에 풀어야 하는 과제였음.
과정
경쟁 금융앱 부가서비스 구조 직접 비교 분석 → 개선 포인트 도출. 청년미래적금 정책 발표에 맞춰 기존 청년도약계좌 이용자가 자연스럽게 갈아탈 수 있도록 연결 프로세스·유도 화면·가입 흐름 전 구간 재설계. 위젯 서비스 개선으로 포인트쌓기 페이지 직접 연동, 잔액조회 기능 개선 및 포인트·혜택 페이지 개선 병행.
결과
이용자 수 증가 NH올원뱅크 농협 고객 내 이용자 수 증가 및 대표 금융앱 인지도 상승 기여. 중년층 금융·비금융 서비스 이용 편의성 개선, 다양한 진입점 확대로 사용자 접근성 확대.
금융 UX 청년도약계좌 위젯 개선 혜택 페이지 운영 고도화
NH모바일신분증 구축 · 론칭
WHY
출시 후 타 금융앱 대비 발급률이 한 자릿수 증가 수준에 그침. 발급량이 낮으면 신분증 기반 금융 서비스 이용률 전반에 직결되는 구조로 사업 목표 달성에 위협 요소로 판단.
과정
경쟁 금융앱 발급 프로세스를 단계별로 직접 따라가며 비교 분석 → 불필요한 API 호출이 발급 속도 지연의 기술적 원인임을 기획자 단계에서 직접 확인. 인증 방식 전면 교체 vs 단계 간소화 두 방향 검토 후, 개발 일정·리소스를 고려해 단계 간소화 우선 선택. 전 기종 호환 통합 인증 구조 설계, OS별 예외 케이스 UML 기반 사전 정리.
결과
발급률 한 자릿수 → 두 자릿수 개선 후 1,000명 이상 꾸준히 발급 시도 확인. 메인화면 진입 속도 최대 4~5초 → 3초 단축. iOS·Android 전 기종 호환 통합 인증 프로세스 설계 완료.
신분증 인증 UX API 구조 분석 전 기종 호환 발급 프로세스 개선 UML 설계

삼성카드 앱 고도화 운영
WHY
신규 카드 발급 고객의 초기 이용률이 낮으면 장기 이탈로 이어지는 금융 서비스 특성상, 웰컴 혜택이 단순 안내 중심이어서 실제 카드 사용 유인이 부족하다는 문제 분석. VIP 고객 혜택도 한눈에 파악되지 않아 장기 고객 이용성 저하 우려 식별.
과정
경쟁사 웰컴·VIP 혜택 구조 분석 → 오퍼월 미션형 이벤트 도입 결정. 매달 30만 명 이상 신규 고객 규모를 고려해 내부 CMS 이벤트 관리 구조를 그룹화해 운영 효율화 병행. 관계사 임직원 복지 혜택 서비스 신규 설계 시 초기 기준·가이드라인 선제 제시로 디자인·개발 혼선 차단.
결과
월 30만+ 고객 대상 웰컴 서비스 접근율 개선 및 초기 이용 활성화 확인. VIP 혜택 서비스 이용성 증가, 관계사 임직원 복지 서비스 제한 일정 내 안정적 출시.
웰컴혜택 설계 오퍼월 미션 CMS 운영 구조화 임직원 복지 신규 VIP 혜택
롯데홈쇼핑 앱 고도화
WHY
앱 내 상품 콘텐츠 노출 구조가 비효율적으로 주요 상품 정보를 한눈에 파악하기 어려운 UX 문제 식별. 데이터 기반 개선 환경 자체가 부재해 사용자 행동 데이터 수집 구조 구축이 선행 과제로 도출.
과정
경쟁 서비스 벤치마킹·사용자 편의성 분석으로 상품 모듈 구조 재정의. UX 개선과 동시에 GA 이벤트 트래킹 체계를 기획 단계에서 함께 설계해 메뉴별 클릭률·상품 진입 경로 등 측정 가능한 구조 구축.
결과
GA 수집 환경 구축 상품 모듈 구조 개선 완료 및 마케팅·운영 조직과의 데이터 협업 기반 마련.
